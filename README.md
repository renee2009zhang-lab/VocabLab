# SAT 词汇练习

一个无需安装、无需构建的静态词汇练习网页。

## 词表与功能

- 核心词汇：300 个词，用于功能演示。
- 每组 50 个词，共 6 组。
- 支持闪卡背诵、智能抽背、拼写默写和词汇总览。
- 支持模糊词星标、闪卡重复巩固和随机练习。

## 文件

`index.html` 是完整网页，包含词表、样式配置和交互逻辑。直接打开即可使用，也可以作为 GitHub Pages 的首页。

上传时，将本文件夹内的 `index.html` 和 `README.md` 放在仓库根目录。

## 使用说明

页面的 Tailwind CSS 和 Font Awesome 从在线 CDN 加载，因此正常显示需要联网。无需安装 Node.js 或运行构建命令。

星标保存在当前浏览器的本地存储中，不会自动同步到 GitHub、其他浏览器或其他设备。从本地文件切换到网站地址时，原有星标不会自动迁移。
